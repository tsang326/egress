## Spec 1 — fire-zone (two-zone compartment fire model)

`src/core/fire/`: a TypeScript re-implementation of the core of NIST CFAST 7.7.7 (two-zone model), pure functions,
no DOM, runnable in a Web Worker and in Node. Source of every equation: *CFAST Technical Reference Guide* 7.7.7
(`docs/refs/CFAST_Tech_Ref.pdf`); each function cites the equation or section number it implements.

**In scope**
- Compartments: box rooms (width, depth, height, floor elevation), wall/ceiling/floor material
  (conductivity, density, specific heat, thickness, emissivity). Up to 30 compartments plus the outside, on up to
  6 floors (each compartment has a floor elevation; floors are stacked).
- Two layers per compartment: upper layer temperature, lower layer temperature, upper layer volume, pressure
  (Tech Ref eq. 2.5–2.8), constants cp = 1012 J/(kg·K), γ = 1.4 (eq. 2.1).
- Wall vents (doors, windows, open or closed, can change at a given time): two-way flow by Bernoulli with
  neutral planes (Tech Ref 4.1). Leakage as a small vent (4.4).
- Ceiling/floor vents (Tech Ref 4.2) to connect floors: open stair wells, floor openings, roof hatches. A stair is
  modelled as its own compartment per floor joined by floor/ceiling vents. Every result that depends on a stair or
  shaft carries a warning flag, because the Tech Ref (1.5) says CFAST's correlations were developed for rooms, not
  corridors or vertical shafts. No fans/HVAC.
- Fires: heat release rate as a time table (time, HRR, height, area, CO/soot yields), position in the room,
  radiative fraction, fuel chemistry (C, H, O, N, Cl, heat of combustion). Oxygen-limited burning (lower oxygen
  limit, Tech Ref 3.1–3.2). Plume entrainment for centre, wall and corner fires (3.3).
- Heat transfer: point-source fire radiation and layer radiation (5.1, simplified as the Tech Ref allows),
  convection to surfaces (5.2), 1-D conduction in each surface (5.3, implicit scheme).
- Species per layer: O2, CO2, CO, H2O, soot (mass fractions), optical density, visibility (6.2).
- Solver: the system is stiff (Tech Ref appendix C). Implement an implicit integrator (BDF1/BDF2 with Newton
  iterations and a finite-difference Jacobian, adaptive step with error control). No external numeric library
  unless its licence is MIT/BSD/Apache and it is pinned.
- Output: a time series at a fixed print interval (default 1 s) per compartment: upper/lower temperature,
  layer interface height, pressure, species, visibility, HRR actually burned; per vent: mass flows in/out.

**Out of scope (later specs or never)**
Sprinklers, detectors, suppression, HVAC, targets, secondary ignition of objects (spec 2),
tenability/FED (spec 2), crowd movement, any UI.

**Validation (the gate)**
- `tools/cfast/`: a script that runs a local CFAST 7.7.7 binary on every input in `validation/cases/` and writes
  the reference CSVs to `validation/reference/`. CFAST is NOT bundled or called at runtime; only its outputs and the
  NIST input files are committed, with the NIST software notice kept intact and attribution (see `safety.md`).
- Cases: CFAST `Verification/Energy_Balance`, `Mass_Balance`, `Ventilation`, and 8 Steckler compartment cases
  covering door widths 0.24, 0.49, 0.74, 0.99 m and centre/wall/corner fire positions; the DelCo Trainers cases
  (Validation/DelCo_Trainers, multi-storey buildings with ceiling vents, CFAST Validation Guide 4.2) for floors.
- Pass criteria vs CFAST, after the first 60 s: upper and lower layer temperature *rise* within ±5 %, layer interface
  height within ±0.10 m, vent mass flow within ±10 %. A report `validation/REPORT.md` is generated by a script
  (table per case, plus a column with CFAST vs measured Steckler values typed in from the CFAST Validation Guide,
  with the page cited). Measured experiment files are not committed (their repository states no licence).

**Property-based tests (fast-check)**
- No fire, all surfaces at ambient → state stays at ambient (within 1e-6 relative).
- Mass balance: change of gas mass in all compartments equals net vent inflow plus fuel pyrolysis, within 0.1 %.
- Energy balance within 1 % over a closed-room run (heat released = gas energy change + wall heat + vent outflow).
- 0 ≤ layer interface height ≤ room height; temperatures finite; mass fractions in [0, 1] and summing to 1.
- Closed room, no leakage → oxygen falls and burned HRR drops below the table HRR (oxygen limit).
- Two identical rooms mirrored → identical results; same input → identical output (determinism).
- Single room at steady state: higher HRR → higher upper layer temperature (monotonic).
- Random valid geometries and fire tables → never throws, finishes within a time budget, returns warnings instead of
  NaN.

**Performance budget**
30 compartments on 6 floors, 60 vents, 600 s simulated, 1 s output → under 5 s in a Web Worker on an M-series Mac;
progress events so the UI can show the run. (For scale: CFAST built with -O0 takes 7.9 s for DelCo Test_02, 3 rooms.)

**Not allowed**
Copying Fortran code line by line; the implementation follows the Tech Ref equations. Inventing coefficients:
every constant comes from the Tech Ref or the case input and cites its source.
